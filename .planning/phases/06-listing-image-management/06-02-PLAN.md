| T-06-04 | Tampering | key registration | high | mitigate | Bind canonical key to auth user, draft/listing ID, and existing object in narrowly granted RPC. |
| T-06-05 | Denial of service | concurrent uploads | medium | mitigate | Bucket limits and serialized server count/order allocation. |
| T-06-06 | Information disclosure | draft records and metadata | high | mitigate | Public policies filter `status = 'active'`; owner policy alone admits drafts. Public object URLs for draft bytes are accepted MVP scope and private staging/promotion is deferred. |
