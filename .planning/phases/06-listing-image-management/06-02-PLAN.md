<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Browser → Storage/metadata | A caller can tamper with listing IDs, keys, and counts. |
| Browser → Edge Function | A bearer token and requested resource cross into elevated cleanup. |
| Edge Function → Storage/database | Server authority crosses non-transactional object and SQL systems. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-03 | Elevation | direct deletes/status transition | high | mitigate | Omit browser DELETE policies, deny direct deleted-status updates, and validate JWT ownership in the Edge Function. |
| T-06-04 | Tampering | cleanup sequencing/key registration | high | mitigate | Bind keys to owner/listing/object, remove bytes before metadata, then soft-delete the listing; unit-test ordering. |
| T-06-05 | Denial of service | concurrent uploads | medium | mitigate | Bucket restriction plus serialized database count/order allocation. |
| T-06-06 | Information disclosure | public delivery | medium | mitigate | Public bucket holds canonical application-owned assets only. |
</threat_model>
