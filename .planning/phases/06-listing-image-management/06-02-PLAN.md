## Trust Boundaries

| Boundary | Description |
|---|---|
| Photo manager → image service | UI receives untrusted files and service errors but must not gain provider authority. |
| Query mapping → card | Relation data may be absent, unordered, or include broken public assets. |
| Owner delete action → object/database cleanup | A destructive action crosses browser, Storage, and database boundaries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-06 | Tampering | photo manager | medium | mitigate | Service contract plus database/RLS authority; UI only validates for feedback. |
| T-06-07 | Information disclosure | card image rendering | medium | mitigate | Use only ordered application-owned public URLs and stock fallback; never render legacy arbitrary URLs. |
| T-06-08 | Denial of service | repeated file attempts | medium | mitigate | Config-derived capacity disablement and per-file isolation; server mirrors remain authoritative. |
| T-06-09 | Tampering | listing deletion | high | mitigate | Remove object bytes before metadata/listing delete and preserve state with retryable failure. |
</threat_model>
